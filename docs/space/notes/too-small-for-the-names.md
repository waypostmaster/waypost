## 9. The gate's third fault: a source check that could not fail

Found 2026-09-12 when the sheet desk asked for `source` as one string and the gate had to be changed to
read it. The first version checked `url not in doc` for each declared source, where `doc` was this
handover file, and the catalogue row inside that same file always carries both URLs. **So the check was
satisfied by the claim it was checking, and it printed "2 declared, both linked in the document" over a
sheet whose prose linked nothing.** That line went into section 7 above and into the handover as "both
linked in the sheet one-for-one", and both were sent to the sheet desk before the fault was seen.

What it would have cost: `check:citations` reads `source` as the list of URLs the page must LINK, one
for one with its anchors, so a typeset page with two declared sources and no anchors fails there, or
worse, gets anchors invented by whoever typesets it.

The repair, in three parts. The lede now carries one anchor per source, "Menin Gate" and "Tyne Cot",
each on the name the sources support. The gate now looks for each URL inside the SHEET section only
(between "## THE SHEET" and "## THE CARD"), so a URL in the row, the notes or a correction cannot
satisfy it. And it carries a control for this check specifically: the same sheet with its link targets
stripped must fail. **None of the gate's earlier controls touched `source`,** which is how a vacuous
check sat under a PASS through two handovers. A control proves only the checks it exercises.
