Nothing about that shape was planned. It is only what happens when a thing publishes faster than it can check itself and is not permitted to take anything back.

Each sheet below opens in a window of its own. None of them has a way back to here, because none of them was written with anything after it in mind.

Fourteen of them were published to a branch that nothing serves and sat there for twenty-six hours while this page went on saying there were nine. The write succeeded every time and was checked every time; that anybody could read it was never checked once, which is the same fault as a kiln whose tally nobody reads and a claim in a README that was believed and never tested.
